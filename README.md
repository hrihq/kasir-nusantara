# Kasir Nusantara 🧾

Aplikasi kasir (POS) untuk warung & usaha kecil — **offline penuh**, data tersimpan di perangkat, tanpa server, tanpa langganan.

[![Versi](https://img.shields.io/badge/versi-1.0.0-orange)](https://github.com/hrihq/kasir-nusantara/releases)
[![Platform](https://img.shields.io/badge/platform-Android-green)](https://github.com/hrihq/kasir-nusantara/releases)

## ✨ Fitur

- **Kasir cepat** — keranjang, ubah jumlah langsung, pembayaran **Tunai** (kembalian dibulatkan otomatis) atau **QRIS**
- **Struk digital** — bisa dibagikan setelah transaksi
- **Kelola produk** — foto, harga, stok; menu bisa dikunci dengan **PIN**
- **Laporan harian** — ringkasan penjualan + pencatatan pengeluaran
- **Ekspor Excel** — rekap laporan siap diunduh (.xlsx)
- **Pengingat notifikasi** — pengingat harian sesuai jadwal yang kamu atur
- **Mode gelap** & tampilan landscape

## 📱 Unduh

Ambil APK terbaru di halaman [**Releases**](https://github.com/hrihq/kasir-nusantara/releases) → unduh `KasirNusantara-vX.X.X.apk` → pasang di HP Android.

Setiap pembaruan versi, aplikasi akan menampilkan notifikasi berisi changelog dan tombol unduh langsung dari dalam aplikasi.
